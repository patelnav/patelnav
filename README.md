# Nav Patel

**Builds products from strategy to engineering.**

### Shipped

- **[benchrouter.com](https://benchrouter.com)** — Why are you using the model you use? BenchRouter tests the universe of models, then creates a route that tracks the best one for you.
- **[diarize.io](https://diarize.io)** — YouTube transcription with speaker diarization for AI workflows. [Endorsed by Garry Tan](https://x.com/garrytan/status/2042010645424697497).
- **[timeywimey.co](https://timeywimey.co)** — City-first world clock for distributed lives. Launching on iOS.
- **[snapapp.app](https://snapapp.app)** — iPhone app that turns a prompt into a working mini-app. On the App Store.
- **[ctrlspeak](https://github.com/patelnav/ctrlspeak)** — Triple-tap Ctrl local dictation for macOS. Installable via [Homebrew tap](https://github.com/patelnav/homebrew-ctrlspeak).
- **[baby.cam](https://baby.cam)** — Private-first baby monitor from spare devices. No subscription.
- 🚧 **[iphonesize.com](https://iphonesize.com)** — Visual phone-size comparisons for choosing between iPhone models.
- **[wonamp.com](https://wonamp.com)** — Retro WinAMP-inspired playlist generator. [Source](https://github.com/patelnav/wonamp).
- **[openclaw-youtube-transcript](https://github.com/diarize-io/openclaw-youtube-transcript)** — Open-source OpenClaw integration for YouTube → diarized transcripts.
- **[combine.run](https://combine.run)** — Merge split Strava activities into one clean run or ride. Live with active users.
